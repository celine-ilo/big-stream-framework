# BIG-STREAM

A framework linking digital functions to circular economy strategies for
Africa's circular plastic economy.

This repository sets out the BIG-STREAM framework in a structured, reusable
form. The framework was developed in a book chapter published open access by
Routledge; the chapter is linked below. What is held here is the framework
itself, as data rather than prose, so that it can be applied, extended or
tested against a particular setting.

## The framework

BIG-STREAM is an acronym. The first three letters are digital functions. The
remaining five are circular economy strategies those functions serve.

**Digital functions**

| | Element |
|---|---|
| **B** | Big data analytics and AI |
| **I** | IoT and mobile applications |
| **G** | GIS and remote sensing |

**Strategies**

| | Element |
|---|---|
| **ST** | Sustainable transport and distribution |
| **R** | Responsible production and consumption |
| **E** | Energy recovery |
| **A** | Advise stakeholders |
| **M** | Monitoring and assessing waste management systems |

The chapter addresses three questions: which digital functions are relevant
to a circular plastic economy transition in Africa, which strategies should
be prioritised, and by what mechanisms the functions can be leveraged to
deliver the strategies. The approach is systems thinking applied to a review
of the existing literature and of prior frameworks.

## What the files contain

`framework/elements.csv` holds all eight elements with their type and a
description of what each covers.

`framework/function_strategy_links.csv` holds the mapping between the three
digital functions and the strategies each one supports, with the basis for
each link as stated in the chapter. This is the part that makes the framework
operational rather than descriptive: it says which technology does work for
which strategy, and why.

Seven links are recorded. Only links the chapter states explicitly are
included. Absence of a link means the chapter does not argue for one, not
that none could exist.

## Using it

The framework is a planning instrument. Applied to a specific context, the
usual sequence is to establish which strategies are priorities for that
setting, read across to the digital functions that serve them, and identify
which of those functions are already available, which are feasible and which
are not. That gives a defensible shortlist of digital interventions tied to
stated circular economy objectives rather than selected on novelty.

The chapter is explicit that the framework was built from conceptual studies
and systematic reviews, and that the digital functions discussed are nascent.
It therefore requires validation through quantitative and practical case
studies before it can be treated as more than a structured argument.
